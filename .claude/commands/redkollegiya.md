Используй скил `redkollegiya`. Определи режим обработки по СОДЕРЖАНИЮ входа (не по метке):
готовый текст → Вычитка; бриф/материал → Полный цикл; готовый текст + явная смена голоса → Рерайт.
Прогони «Ядро решений» (класс входа → ветка → оси) одним проходом, напечатай decision-trace,
затем запусти конвейер: Чуковский → (Аграновский ∥ Слопотрон) → single-apply скриптом `apply.py`
из папки скила → Розенталь → Мильчин. Собери ОДИН сводный отчёт. Сама не пиши и не правь:
находки применяет скрипт по дословным цитатам, спорное уходит автору. Аграновский (фактчек)
обязателен, кроме явного «без фактчека». Требуется установленная семья: chukovsky, agranovsky,
slopotron, rozental, milchin (для Полного цикла — bakhtin, vinogradov).
